# Персональные top-10 рекомендации

Домашнее задание 1 по рекомендательным системам, МФТИ.

Студент: **Алиев Гамид Мурадович**.

Датасет: **Amazon Product Data (2014), Beauty, 5-core**.
[Первоисточник и ссылки на данные](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon/links.html).

Реализованы ItemKNN, iALS, EASE, FM с брендом и категориями, ALS с целевым сигналом из оценки и давности отзыва. Обучение, ранжирование и метрики реализованы самостоятельно на NumPy/SciPy. Основная метрика — NDCG@10; дополнительно Recall@10 и покрытие каталога.

## Запуск

Python 3.12. Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run_experiments.py
# Без отдельного Jupyter kernel: python run_experiments.py --in-process
```

Последняя команда выполняет `experiments.ipynb` целиком и сохраняет выводы в нём. Нужен доступ к серверу snap.stanford.edu. Два gzip-файла (~144 МБ) скачиваются автоматически в `~/.cache/rec_sys_mipt`; путь можно изменить переменной `REC_SYS_DATA`. Целостность проверяется SHA-256. Данные, окружение и обученные матрицы не загружаются в Git.

`experiments.ipynb` содержит описание данных, EDA, формулы, единый временной протокол, подбор по validation, финальную таблицу, абляции и выводы. `results/` хранит небольшие таблицы, параметры и агрегаты для проверки чисел. Файлы `users_*.csv` содержат только внутренние числовые индексы и метрики, без исходных пользовательских ID.

Все варианты сравниваются по полному фиксированному каталогу train, с исключением уже известных объектов. Test открывается для финального сравнения после фиксации параметров. Для FM и кастомного ALS дополнительно есть сравнения с ID-only FM и ALS без временного затухания.

Ограничения: выборка 5-core уже отобрана авторами по всему периоду; оценивается warm-start, а не cold-start. Метаданные — снимок каталога: бренды и категории считаются постоянными. Неизвестно, использовался ли этот датасет на семинарах; это нужно сверить со списком курса до сдачи.

Источник: Julian McAuley, Rahul Pandey, Jure Leskovec. *Inferring Networks of Substitutable and Complementary Products*. KDD, 2015.

Для ограничения памяти оставлены 5000 самых популярных объектов train и пользователи с минимум тремя взаимодействиями с ними в train. Правила отбора не используют оценки validation/test.


## Результаты test

| Модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| EASE | 0.02784 | 0.04163 |
| iALS | 0.02763 | 0.04413 |
| CustomALS | 0.02394 | 0.03822 |
| ItemKNN | 0.02344 | 0.03907 |
| FM | 0.01300 | 0.02102 |

После отбора: 113 185 взаимодействий, 15 416 пользователей, 5 000 товаров. На test оцениваются 1 703 пользователей с положительными событиями. Точное описание фильтрации, параметры, абляции и ограничения — в ноутбуке.
